🚀 启动方法

macOS / Linux:

cd imagetool-site && python3 -m http.server 8765

Windows:

cd imagetool-site && python -m http.server 8765

然后浏览器打开 http://localhost:8765

或者双击 start.bat（Windows）/ 执行 ./start.sh（macOS）

📤 部署上线

方案 1 - Netlify Drop（最简单，30秒）

1. 打开 app.netlify.com/drop

2. 把 imagetool-site 整个文件夹拖进去

3. 立即获得 xxx.netlify.app 链接

方案 2 - Cloudflare Pages

1. 注册 dash.cloudflare.com

2. 左侧 Pages → Create a project → Direct Upload

3. 上传 imagetool-site 文件夹，绑定域名
